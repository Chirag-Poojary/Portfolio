PROJECT_01 CV

NoteProof — On-Device Banknote Localization & Counterfeit Detection

Runs fully in-browser
Problem
Counterfeit-currency checks need to be fast and trustworthy without depending on a server round-trip.
Method
A two-stage pipeline. YOLO26n, trained on 7,039 images (including 1,400 hard negatives), localizes the note; a multi-task EfficientNet-B3 trained with a Kendall uncertainty-weighted loss then predicts denomination and authenticity together. Both models run on-device through ONNX Runtime Web (WASM) inside a Next.js + TypeScript frontend.
Outcome
94.4% mAP@0.50 for detection, with 98.4% denomination and 99.0% authenticity accuracy. Live at note-proof.vercel.app. Academic project advised by Prof. Rasika Ransing.
